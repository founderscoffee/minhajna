# 0007. The product is called Tabachir (طباشير)

- **Date:** 2026-09-26
- **Status:** Superseded by [0019](0019-name-minhajna.md)
- **Decided by:** the founder

## Context

With open code, the name is the only thing that separates official builds from forks. So it must be registrable as a trademark. INAPI refuses signs that lack distinctive character (Ordinance 03-06, Art. 7 point 2).

## Options

About 60 names were checked on Google Play Algeria (in Latin and Arabic script), on GitHub, and in the `.dz`, `.com.dz` and `.com` registries. The finalists were checked on the web too.

- **Descriptive names** fail registration, and some echo official documents: the working name "Aqsami" ("my classes"), "Class logbook" (the usual English name of the official class book), and "Almanhaj"/"Alminhaj" (the national curriculum).
- **Religious phrases** were set aside for neutrality. So was every word already used by an education app, and every word whose `.dz` domain was taken.
- **Strong alternatives** were Foggara (فقارة), Guelta (قلتة) and Mizwala (مزولة).

## Decision

**Tabachir** (طباشير): chalk, the teacher's everyday tool. Written in Latin letters, it also reads as تباشير: the first light of dawn, or good news.

- **Latin spelling.** Always "Tabachir", never "Tabashir", which is taken on GitHub.
- **Descriptive line.** It goes under the name, for example "Tabachir: الكراس اليومي ودفتر المناداة والتنقيط".

Checks on 26 Sep 2026:
- the GitHub name `tabachir` was free;
- `tabachir.dz` and `tabachir.com.dz` were free in the registry;
- no app on Google Play Algeria used the name, and no education product on the web did;
- `tabachir.com` was taken.

## Consequences

- **Protecting the name:**
  - reserve the GitHub organisation `tabachir`;
  - register `tabachir.dz` and `tabachir.com.dz`;
  - file the trademark with INAPI through counsel.
- **Future names.** Anything the project names later follows the naming rule in [PRD §1.9](../prd/PRD.md#19-official-builds-releases-the-name-and-security).
