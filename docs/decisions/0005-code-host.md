# 0005. The code lives in a GitHub organisation

- **Date:** 2026-09-26
- **Status:** Superseded in part by [0019](0019-name-minhajna.md) and [0020](0020-code-host-djazairdev.md)
- **Decided by:** the founder

## Context

The code host decides where developers find the project, and how easily it can be handed over later. No pupil data ever goes there.

## Options

- **GitHub:** where developers already are.
- **GitHub with a mirror in Algeria:** for continuity and sovereignty.
- **Codeberg:** a non-profit forge, with a smaller audience.
- **Self-hosted in Algeria:** the strongest sovereignty story, but the least discoverable, and extra work.

## Decision

GitHub, in an organisation rather than a personal account, so that the project can be handed over without breaking links. The repository is [founderscoffee/tabachir](https://github.com/founderscoffee/tabachir), and it is public.

## Consequences

- Every maintainer uses two-factor authentication.
- Issues and discussions are public, so no real pupil data may ever be posted there ([CONTRIBUTING.md](../../CONTRIBUTING.md)).
- The organisation name `tabachir` should be reserved, so that nobody else takes it.
