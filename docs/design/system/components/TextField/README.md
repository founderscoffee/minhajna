# TextField

A labelled input or text area on `sheet`, with a 1.5px `rule` border.

- **Provide** the label (`label`), placed above, and a placeholder that shows an example: «مثال: التمرين 5 ص 22». Say when a field is optional, in its label.
- Inputs are 48px; text areas start at 80px.
- **Canvas:** 59 boards, such as Entry, Setup-3-Card, Calendar-add and Correct.
