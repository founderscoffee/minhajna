# TopBar

The 56px bar at the top of every inner screen: a 48px icon button at each side and a two-line title.

- **Provide** the title (`bar-title`), a subtitle in `bar-subtitle` that places the screen (class, subject, page or date), a back or close button, and at most one action.
- The back icon mirrors in right-to-left layouts (`flip`). Every icon button carries an `aria-label`.
- **Canvas:** 200 boards, such as P09, Roll and Entry.
