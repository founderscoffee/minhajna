# ProcessSteps

The steps of a process that others take part in, such as sending the term's marks or publishing a threshold: done, waiting, to come.

- **Done:** a `board` dot with a tick. **Waiting:** a dashed `notice` dot. **To come:** a `track` dot.
- **Provide** each step's name and one line of detail. Say who acts, never when someone acted.
- **Canvas:** Term-send, T-Threshold, D-Threshold, M-Threshold, Obs-Report. PRD [§7.10](https://github.com/founderscoffee/minhajna/blob/main/docs/prd/PRD.md#710-exam-thresholds).
