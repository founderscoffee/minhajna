# SetupSteps

The thin bar of steps at the top of Getting started: one segment per step, `board` once reached.

- **Provide** the number of steps and how many are done. It is decoration for sighted users (`aria-hidden`); the screen's title says the step.
- **Canvas:** Setup-2-Teaching to Setup-6-Plan, with Setup-2b-Schools and Setup-5a-Wait, and Devices-join on the web. PRD [§3.2](https://github.com/founderscoffee/minhajna/blob/main/docs/prd/PRD.md#32-getting-started).
