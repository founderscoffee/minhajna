# Snackbar

A short confirmation on `board` after a quick action, with a way to undo it.

- **Provide** one line in the past tense saying what happened, such as «كُتبت الحصة في دفتر النصوص», and the action «تراجع» in `hi`.
- It sits above the bottom navigation, with `shadow-snack`, and is announced as a status.
- **Canvas:** Today-done, Today-backlog, Today-backup, Entry-fix, Sheet-nostage, Session-extra, P10-4m1. PRD [§3.1](https://github.com/founderscoffee/minhajna/blob/main/docs/prd/PRD.md#31-design-rules) rule 4.
