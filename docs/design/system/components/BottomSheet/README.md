# BottomSheet

A sheet over the screen for a short decision, such as how a session went when it did not go as proposed.

- **Provide** a title (`h3`), a line that names what it is about (`sub`), the choices, and a reassurance at the foot.
- The sheet is `sheet` with `radius-chip` top corners and `shadow-sheet`, over a `scrim`. Every sheet can be closed without choosing.
- **Canvas:** Sheet, Sheet-nostage, Sheet-reason, Entry-lesson, Print, Doc-output, Doc-output-pupils, Export-file, Share-to, Pupil-erase, Exam-window, Sept-check, Roll-seats, Share-warn, Devices-add, Device-remove, Today-backup.
