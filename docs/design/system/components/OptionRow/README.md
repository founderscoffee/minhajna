# OptionRow

A full-width choice with an icon and an optional second line, as in the outcomes of a session: merged, skipped, re-taught, not held.

- **Provide** the icon, the label and a second line (`sub`) when the choice needs one.
- Say where private things stay: «ذكر السبب اختياري، ويبقى على الهاتف» (PRD [§5.4](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#54-where-each-record-may-go)).
- Rows are at least 52px, with a 1.5px `line` border on `sheet`.
- **Canvas:** Sheet, Sheet-nostage, Apprec, Apprec-conduct, Plan-stale. PRD [§3.3](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#33-today-and-the-session).
