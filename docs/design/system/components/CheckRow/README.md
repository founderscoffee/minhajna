# CheckRow

A checkbox with its label as one row, for the stages done in a session or a one-off fact such as «أُجري فرض في هذه الحصة».

- **Provide** the label. The box is 22px, in `board` once checked.
- **Size:** the canvas draws these rows at 44px. Build them at 48px (see Accessibility).
- **Canvas:** Catchup-add, Entry, Entry-fix, Marks-setup, Marks-setup-sum, Pupil-move, Rejoin, Sheet-reason, Signature.
