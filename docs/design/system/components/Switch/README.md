# Switch

An on-or-off setting that takes effect at once, such as notifications, sync over Wi-Fi only, or the drawn signature.

- **Use it inside a full-width row** that is the touch target, with the setting's name and, if needed, one line saying what it does.
- **On:** a `board` track. **Off:** a `rule` track.
- Off by default for anything that shares or sends. Insights are opt-in (PRD [§6.8](https://github.com/founderscoffee/minhajna/blob/main/docs/prd/PRD.md#68-non-functional-requirements), §1.6).
- **Canvas:** Settings, Notif, Devices, Insights-optin and 22 more.
