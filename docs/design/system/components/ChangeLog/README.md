# ChangeLog

The history of a record, one line per change, with the day and what changed. Corrections are listed, never hidden.

- **Provide** one line per change: the day, what changed, and the reason where one was given (PRD [§5.5](https://github.com/founderscoffee/minhajna/blob/main/docs/prd/PRD.md#55-history-corrections-and-signatures)).
- **Days only, never clock times.**
- **Canvas:** Pupil, Log.
