# Badge

One or two words of state beside a title, such as «مؤكّدة», «مثال» or «بانتظار».

- **Default:** `pill-on` ground with `ink2` text. **Done:** `ok` with `ok-ink`. **Warning:** `notice-strong` with `notice-ink`.
- **Every badge is a word.** No badge rates a teacher (PRD [§2.6](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#26-what-minhajna-never-does)).
- **Canvas:** 76 boards. On the national boards «مثال» marks the example year.
