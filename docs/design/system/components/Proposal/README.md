# Proposal

What the plan proposes for a session, in pencil: a dashed box, `pencil` text and a tag that says where it comes from.

- **Provide** the tag (`tag`), such as «مقترح من المخطط» or «مقترح من المخطط · يتابع من الحصة السابقة», then the domain, the topic and the stages, as they will be written in the book.
- **Never draw a proposal in ink.** Once the teacher confirms, the same text moves to the book in `ink` (PRD [§3.1](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#31-design-rules) rule 3).
- The 1.5px dashed `pencil-edge` border is 2.3:1, so the tag must always be there.
- **Canvas:** Main, Today-done, Today-ramadan, Today-saturday, P-Today, L-Today, EN-Today, Plan-lycee, Setup-7-Ready, Week-sign, Week-sign-today, Sheet-nostage. PRD [§4.7](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#47-the-engine).
