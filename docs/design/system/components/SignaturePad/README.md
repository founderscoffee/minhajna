# SignaturePad

Where the teacher draws a signature once, to print on confirmed entries if they choose.

- A dashed `pencil-edge` pad, 190px tall, with a baseline. The stroke is `signature` blue.
- **The teacher's choice:**
  - off by default;
  - only on entries the teacher confirmed;
  - printouts and PDFs only;
  - never synced or backed up.
- Only the image is kept, never the strokes' speed or timing (PRD [§3.8](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#38-the-documents)).
- **Canvas:** Signature.
