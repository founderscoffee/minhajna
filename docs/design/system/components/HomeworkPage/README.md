# HomeworkPage

The texts book's homework record: each homework with the date set and the date due, and two class counts with their percentage.

- **Provide** for each homework:
  - the dates;
  - the activity;
  - the two counts: did not do it, and relied on someone else.
- **Counts and percentages only, never names.** A percentage is of the pupils on the class list, rounded to a whole number (PRD [§3.8](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#38-the-documents)).
- **Today's homework** carries the `today` tag and Steppers, with «الجميع أنجزه بنفسه» to set both counts to zero.
- **Canvas:** P67.
