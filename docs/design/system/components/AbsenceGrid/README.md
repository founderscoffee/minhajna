# AbsenceGrid

The month's roll call as a grid: one row per pupil, one column per day, then the totals.

- **Header:** day numbers (`grid-head`) with the day's initial.
- **Rows:** names in Arabic, and counts in `grid-figure`. Totals columns are on `due`.
- A tappable row is `link-row` and opens the pupil.
- **Provide** the days, the pupils and their counts, and a legend of the abbreviations under the grid.
- **Canvas:** Month. PRD [§3.4](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#34-roll-call-the-digital-roll-call-book).
