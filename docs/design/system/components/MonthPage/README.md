# MonthPage

A small ruled table in the book's style, for figures such as a pupil's roll-call totals or an imported list.

- **Provide** the header cells (`month-head`) and the rows. Figures use Noto Sans.
- **Canvas:** Pupil, Pupil-year, Print, Repace, Setup-4b-Import, Council-t2. PRD [§3.4](https://github.com/founderscoffee/minhajna/blob/main/docs/prd/PRD.md#34-roll-call-the-digital-roll-call-book).
