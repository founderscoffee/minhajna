# Facts

Short promises with an icon, each one a fact the app keeps: no account, offline, the data stays on the phone.

- **Provide** three facts at most, each one line, with a `board` icon.
- `kept` is the same idea after a step: what was saved or kept, each with a tick. A crossed-out `kept no` is what was not.
- **Canvas:** Setup-1-Welcome; `kept` on 101 boards, such as Setup-7-Ready and Year-close. PRD [§3.2](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#32-getting-started).
