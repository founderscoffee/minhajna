# Stepper

A count changed one at a time, such as the pupils who did not do their homework.

- **Provide** the value, its unit line (`pc`), and an `aria-label` on each button that names the count. The value is announced (`aria-live`).
- The buttons are 48px with a 1.5px `rule` border. The value uses the `stepper` style.
- **Canvas:** P67, Marks-setup, Marks-setup-sum, Plan-free, Plan-item, Roll-seats-setup. PRD [§3.8](https://github.com/founderscoffee/minhajna/blob/main/docs/prd/PRD.md#38-the-documents).
