# Logo

The app icon, the chalk «م» alone, the wordmark «منهاجنا» in Aref Ruqaa, and the Arabic and Latin lockups.

- **Use** the icon for the app, the store, the website and the web app's tab. Use the letter alone in `chalk` on `board` surfaces, and in `ink` on paper and in print. Use the Arabic lockup where the name must appear beside the icon, such as the website's header and the README.
- **Provide** nothing: the files are in the asset group Logos. The wordmark and the Arabic lockup are outlined, so they need no font. On screens that set the name as text, such as the welcome hero, use the `brand` style. The Latin lockup is still live text in Noto Sans SemiBold.
- **Don't** recolour the letter, set the wordmark in another face, or put the logo on a document a director or an inspector checks.
- **Who may use it.** Only the project's own builds carry this logo. The Ministry's deployment shows its own name and icon, and forks use another name and logo (PRD [§1.9](https://github.com/founderscoffee/minhajna/blob/main/docs/prd/PRD.md#19-official-builds-releases-the-name-and-security), `TRADEMARKS.md`). See the Logo section.
