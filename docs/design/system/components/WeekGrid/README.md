# WeekGrid

The weekly timetable at a glance: days across, slots down, each class on its subject colour.

- **Provide** the working days, the slots, and the class in each slot. Empty slots stay `sheet`.
- **Slots only, never clock times.** Ramadan's times come from the calendar, not the timetable (PRD [§4.6](https://github.com/founderscoffee/minhajna/blob/main/docs/prd/PRD.md#46-how-sessions-are-generated)).
- **Canvas:** Setup-5-Week, Setup-5b-Package, TT-change, TT-change-day, Repace-primary.
