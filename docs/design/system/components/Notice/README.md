# Notice

Information that comes before a step: a reassurance in one line, or a dashed notice for something to do first.

- **Reassurance** (`warn`): an 18px icon and one `small` line in `ink2`, such as «يمكن تصحيح أي حصة لاحقاً، ويُحفظ كل تعديل.»
- **Notice** (`notice`): a 1.5px dashed `notice-edge` box on `notice`, for something that needs a step before going on, such as recovering the school key when no device holds it. Use the warning badge (`badge wn`) for one word.
- **Never use a notice to scold.** State what to do and why.
- **Canvas:** reassurances on 79 boards. Notices on Entry-fix, Roll-past, D-Keys, E-Migrate, Digest-signed, Digest-closure, Handover-school, Term-send, Calendar-update-today, Today-ramadan, Transfer, Web-unlock-risk and the threshold boards.
