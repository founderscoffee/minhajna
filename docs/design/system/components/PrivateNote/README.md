# PrivateNote

The panel for what stays on the teacher's own devices: private notes, and the reason a session was not held.

- **Use** it for anything in the private layer. Its ground, `private`, and its lock icon set it apart from what goes into the book.
- **Provide** the label with «لا تغادر أجهزتك» (private notes sync, encrypted, between the teacher's own devices), the field, and the reminder «يُرجى عدم كتابة تفاصيل صحية أو تأديبية تخص التلاميذ، هنا أو في الدفتر.»
- Nothing in this panel ever reaches a statement, a school space or a total (PRD [§5.4](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#54-where-each-record-may-go)).
- **Canvas:** Entry, Correct, Erase, Export and 60 more.
