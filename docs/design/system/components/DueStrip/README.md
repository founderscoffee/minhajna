# DueStrip

A strip inside a session card for what goes with the session: the roll call, or homework due back today.

- **Provide** an 18px icon, one line of fact and one soft button that opens the task.
- Say the fact plainly: «لا غياب مسجّل», «يُسلَّم اليوم: التمرين 2 ص 21».
- **Canvas:** Main, Class, Note, P-Today, EN-Today, PS-Today, Today-exams, Today-ramadan, Digest-closure.
