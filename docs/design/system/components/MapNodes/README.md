# MapNodes

The pieces of the web maps that show who holds what: nodes, groups, link labels and the attribution.

- **Nodes:** `sheet` with a `rule` border. A node that holds a key is `board`. A node with no key is dashed on `well`. A removed device is dashed on `node-gone`.
- **Links:** 2px `map-edge`, dashed when planned. Their labels are `el`.
- **Maps are for reading.** Nothing changes by dragging (PRD [§5.2](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#52-architecture)).
- **Canvas:** D-Exchange, D-Keys, Ops-Console, and the pack editor's release map. PRD [§6.5](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#65-keys-sync-and-recovery), [§7.5](https://github.com/djazairdev/minhajna/blob/main/docs/prd/PRD.md#75-the-schools-space).
