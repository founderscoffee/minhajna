- **معطيات التلاميذ لا تغادر جهاز الأستاذ.** المشروع لا يستقبلها ولا يطّلع عليها أبدًا.
- **لا إشهار ولا تتبّع ولا بيع للمعطيات، أبدًا.**
- **كل ميزات التطبيق مجانية.** يموَّل المشروع بخدمات، كالمزامنة المشفّرة، لا بحجب الميزات.
- **الأستاذ يملك سجلاته**، ويمكنه تصديرها كاملة ومجانًا في أي وقت.
- **أداة في يد الأستاذ، وليست السجل الرسمي.**
- **كل شيء علني:** الكود والقرارات وخارطة الطريق.

## English

**Tabachir** is an open-source app for teachers in Algeria. It brings together the daily lesson journal (الكراس اليومي), the roll-call register and the marks book. It works offline on the phone and prints the documents the director and the inspector ask for.

> **The project is in planning; there is no app yet.** Any app called "Tabachir" today is not ours.

### Principles

- **Pupils' data never leaves the teacher's device.** The project never receives it and can never read it.
- **No ads, no trackers, no sale of data. Ever.**
- **Every feature of the app is free.** Services such as encrypted sync pay for the project; features are never locked.
- **Teachers own their records** and can export all of them, for free, at any time.
- **A teacher's tool, not the official record.**
- **Everything in the open:** code, decisions and roadmap.

### Contributing now

- Share feedback, suggestions, corrections to annual plans, and templates through [Issues](https://github.com/founderscoffee/tabachir/issues).
- **Never post pupils' names, marks or absences, or images of them**, anywhere in the project. Use made-up names.
- Code contributions are by invitation until the launch, planned for September 2027. See [CONTRIBUTING.md](CONTRIBUTING.md).
